# edge-detection-for-images
A programme that tells user to input image path and convert that image to a only show the edges. This is part of a broader project that converts images to mathematical equations. 

## Features 

- User input
- Converts image to Graph

## Installation

- Go the the Github Release of this project
- Download and extract edgeDetect.zip
- Run .exe and paste the image path when prompted.

## To run locally

- Clone this repo
- Run this command in terminal to install required libraries `pip install opencv-python matplotlib`
- Run edgeDetect.py

## About this project

This project is the earliest version of my image to graph converter. It's basically the bare bones of it

## Techstack 

- OpenCV
- Matplotlib
