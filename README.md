# edge-detection-for-images
A programme that tells user to input image path and convert that image to a only show the edges (https://github.com/cziwu12/Raster-Image-to-Equation-Converter). This is part of a broader project that converts images to mathematical equations. 

This project is the earliest version of my image to graph converter. It's basically the bare bones of it. It's also my first computer vision project so yeah, kinda nice. I don't really have anything to say for this project as to me, this project is basically input in output sth type of project so yeah.

## Installation

- Go the the Github Release of this project
- Download and extract edgeDetect.zip
- Run .exe and paste the image path when prompted.

## To run locally

- Clone this repo
- Run this command in terminal to install required libraries `pip install opencv-python matplotlib`
- Run edgeDetect.py

## Techstack 

- OpenCV
- Matplotlib
